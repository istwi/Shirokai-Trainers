# Shirokai Trainers 0.3.0 — NPCs nativos

Pré-release para Minecraft 1.21.1 / Fabric / Cobblemon 1.8.3+1.21.1.

Criação e administração de NPCs nativos do Cobblemon, vínculo por clique a NPCs existentes, aparência e skins PNG locais, mensagens/confirmacão e desafio pelo serviço de batalhas existente. Não requer EasyNPC. Treinadores e progresso existentes são preservados.

Consulte `NPCS-COBBLEMON.md` para comandos, exemplo completo, persistência e limitações. O JAR desta release só é enviado após build e testes passarem no GitHub Actions. Aceitação com clientes, aparência, clique, reinício/chunks e MultiWorld continua pendente; esta pré-release não declara esses cenários validados.
